<h1 align="center">DailyWorkMate</h1>
<p align="center">把 AI 助手、工作区、终端和模型管理放在一起的桌面工作搭档。</p>
<p align="center">简体中文 · <a href="README.md">English</a> · <a href="docs/installation_CN.md">安装指南</a> · <a href="LICENSE">GPL-3.0</a></p>

DailyWorkMate 帮你把每天的计划接到实际工作上：与 AI 讨论问题、整理待办，让代理在授权文件夹中处理文件，在终端运行命令，并在同一个窗口管理模型、查看请求和 Token 用量。支持自己的 API 服务、Ollama 节点，以及 OpenCode 和 Kilo 提供的免费模型入口。

## 功能一览

左侧导航按工作流程整理为六个入口，相关配置在各页面内集中管理。

| 入口 | 可以做什么 |
| --- | --- |
| **助手** | 聊天规划、Daily Todo、语音与角色；切换工作区和真实终端。 |
| **AI 对话** | 独立的模型聊天，支持任务提示词、翻译目标语言、附件和会话历史。 |
| **用量监控** | Token 用量、趋势与模型分布；查看请求日志和应用日志。 |
| **模型接入** | 集中管理供应商与账号、Ollama 节点、模型列表和模型映射。 |
| **API 服务** | 代理监听地址、本地 API Key、负载均衡、会话与上下文、高级参数。 |
| **设置** | 主题、语言、字体与显示选项，以及应用信息。 |

## 助手与 Daily Todo

![助手界面与每日计划示例](docs/screenshots/assistant.png)

- **聊天与规划**：流式回复、会话历史、模型选择；可以修改助手名字和角色设定。
- **待办便签**：聊天提到 DailyTodo、Daily、Todo 或待办，或授权目录中有相关文档时，可显示纸张风格的 Markdown 便签，支持标题、嵌套清单、表格、引用和代码。
- **直接管理任务**：添加、编辑、确认删除任务，切换“待办／进行中／已完成”；编辑保留说明和子任务，保存前检查外部文件修改冲突。个人便签保存在本地，工作区便签遵循目录权限。
- **延续每日计划**：“拷贝最新”复制完整便签；“拷贝未完成”保留待办、进行中事项和未完成子任务。副本使用当天日期命名，原文件保留。
- **语音与形象**：麦克风输入、可开关的自动朗读、全文或摘要朗读；支持系统语音、可选本地语音和兼容语音 API。角色可使用内置章鱼、自定义图片或受支持的 GLB/GLTF 模型。
- **从聊天进入工作**：连接工作区且模型支持工具时，可以把文件任务交给工作区代理。

## 工作区：让 AI 在授权目录中处理任务

![授权文件夹、分组与读写权限](docs/screenshots/workspaces.png)

把文件夹拖入应用，或通过“添加文件夹”选择目录，再指定“只读”或“可编辑”。可把相关目录组成工作区分组，也可将单次任务收窄到某个子目录。

- **原生代理会话**：支持 OpenCode 和本机 Claude Code，每个工作标签绑定自己的目录或分组，模型、引擎与访问范围清楚可见。
- **多任务并行**：多个工作标签可同时运行；切换到聊天或其他页面时，正在运行的会话继续保留。
- **文件与任务过程**：浏览授权文本文件、附加内容到对话，查看回答、工具调用、错误和权限请求，并随时停止任务。
- **会话历史与恢复**：从“最近会话”重新打开对话；终端显示中断时可接回仍在运行的服务。服务已停止时，需要明确重新启动，恢复的记录不会自动续跑旧进程。
- **权限变更**：受影响的旧任务停止，由用户明确再次启动后使用新权限，无关目录会话继续运行。
- **专注模式**：全屏保留标签和控制栏，可收起页面标题；提示、模型选择和终端选项集中在同一行。

文件夹权限约束代理工具的访问。Shell 命令以当前系统用户权限运行；较窄范围无法可靠约束命令时，相应工作模式会禁用命令执行。

## 终端：保留工作现场，随时切换任务

![PowerShell 与 CMD 终端标签](docs/screenshots/terminal.png)

终端使用真实 PTY，Windows 下支持 **PowerShell、CMD 和已安装的 WSL 发行版**。

- **多标签与分屏**：每个标签最多四个窗格，每个窗格独立运行 Shell；可拖动分隔条调整布局。
- **恢复目录与布局**：保存未关闭标签、窗格、Shell 类型和目录；重启应用后按需启动新 Shell。应用运行期间切换页面保留现有进程。
- **任务状态可见**：运行中的任务显示动态标记，完成后显示对勾，空闲时显示空心标记；从聊天页也能观察工作区和终端状态。
- **目录联动**：拖入文件夹可直接在该目录打开终端；底部路径跟随 `cd` 更新，并可在文件管理器中打开。
- **输出操作**：选区复制、可调整的滚动历史、显示重绘，以及全屏专注模式。
- **退出控制**：退出时等待普通终端和工作进程停止；检测到 psmux 会话时，可选择关闭、保留或取消退出。最小化到托盘可继续运行。

| 常用操作 | 快捷方式 |
| --- | --- |
| 复制终端选区 | Ctrl+C / ⌘C、Ctrl+Shift+C 或右键；无选区时 Ctrl+C 中断命令。 |
| 程序接管鼠标时选字或回看历史 | 按住 Shift 拖动或滚动。 |
| 向右／向下拆分 | Alt+Shift+= / Alt+Shift+-。 |
| 切换窗格 | Alt+方向键。 |
| 进入／退出专注模式 | F11；终端内的 Esc 继续交给当前程序。 |

## 用量监控：看清趋势、模型分布与请求表现

![Token 用量监控，使用虚构演示数据](docs/screenshots/monitor.png)

- **7／30／90 天视图**：查看期间 Token、请求数、失败数、成功率和平均完成耗时。
- **消耗趋势**：切换 Token 与请求指标，通过悬停或键盘查看每天的数据；点击模型可筛选趋势，上方汇总仍显示全部模型。
- **模型占比**：查看各模型消耗和请求量，展开完整模型列表。
- **13 周活跃热力图**：查看活跃日期、每日请求与 Token，以及期间峰值。
- **历史完整性提示**：统计历史至少保留 180 天；旧版本已经清理的数据标为不可用，历史不足时暂停环比，避免将缺失数据当零。
- **日志联动**：从近期请求进入对应日志详情；请求日志和应用日志分别查看。页面可见时每 10 秒刷新，也支持手动刷新。

统计范围是本应用已经记录的用量。部分原生直连、内部摘要及未返回 Token 的上游响应尚未完整计入；账户额度和费用以服务商为准。

## 模型接入与全局路由

| 模型来源 | 功能 |
| --- | --- |
| **供应商与 API** | 内置渠道、API Key 预设、自定义兼容接口、多账号和模型映射。 |
| **Ollama** | 本地或局域网节点、节点扫描与批量导入、鉴权、模型刷新及连接检查。 |
| **OpenCode 免费模型** | 动态免费目录与模型能力信息；支持的入口可用于聊天、工作区或兼容代理。 |
| **Kilo 免费模型** | 根据上游免费目录加载，无需个人 API Key；工作区调用要求模型支持工具。 |

**模型接入 → Ollama 节点 → 全局模型路由** 提供两种选择：

- **强制使用指定模型**：把适用的 API 请求统一路由到选定模型；可选择 Ollama 或支持的免费模型目标。
- **路由原始请求模型**：按客户端请求的模型名称选择可用节点，保留客户端的模型选择。

两项能力保留在同一配置中，强制模型开启时优先使用指定目标。提供路由测试按钮；保存的目标不可用时保留选择并报告错误。桌面聊天中明确选择的模型不受全局强制设置替换。

免费入口的目录、可用性和额度由上游控制；模型出现在列表中并不保证当前可以免费推理。图像、思考、联网和工具能力也取决于实际渠道与模型。详见[供应商参考](docs/providers/README.md)与[免费模型连接](docs/free-models.md)。

## API 服务：让其他客户端复用模型配置

- **兼容接口**：提供 OpenAI Chat Completions、Anthropic Messages，以及 Ollama 模型列表和聊天兼容接口。
- **统一接入**：其他客户端可复用供应商、Ollama 和支持的免费模型，无需逐个维护相同配置。
- **服务管理**：管理监听地址与端口、本地 API Key、负载均衡、失败重试、超时和模型映射。
- **上下文与工具适配**：按渠道能力配置工具调用，使用滑动窗口、Token 限制或摘要策略管理上下文。

## 外观与使用偏好

支持中英文、明暗主题、字体与字号调整、侧边栏收起或隐藏，以及需要重启生效的 GPU 合成选项。助手、工作区和终端可按任务切换，窗口较窄时布局相应调整。

截图来自实际应用，使用虚构的对话、目录与用量；终端截图使用本地 PowerShell。当前桌面验收以 Windows 为主。
